# Samples

Each section below is one run of [`fill`](api.md#xlsxfill.fill), laid out as
three tabs.

| Tab | What it holds |
|---|---|
| **Template** | The workbook the run opens |
| **Input** | The data merged into it |
| **Expected** | Under **Filled** — the workbook the run wrote |
| **Error** | Under **Rejected** — the exception raised instead |
